# 2026、2027 假日資料來源

- 原始資料：行政院人事行政總處「中華民國政府行政機關辦公日曆表」，政府資料開放平台：https://data.gov.tw/dataset/14718 。
- 本次資料取得：2026-11-12。執行環境無法直接連線人事行政總處網站（網路政策回應 CONNECT 403），採用明確標示上述原始資料來源的 TaiwanCalendar 格式轉換鏡像，沒有聲稱直接讀取官方公告原檔。
- 鏡像與固定版本：https://github.com/ruyut/TaiwanCalendar/tree/73d814e768c94f2426af0787c96658d69068c3ff 。
- 原始鏡像檔：`data/2026.json`、`data/2027.json`。各有 365 日；擷取 `isHoliday === true` 且 `description` 不為空的記錄，保留原始名稱。
- 本地整理檔：`src/data/taiwan-holidays.json`，共 46 日（2026 年 22 日、2027 年 24 日），包括落在週末的國定假日與補假。一般週末只以日期顏色呈現，不另外建立假日名稱。
- 原始說明為「補假」時保留「補假」，不自行猜測該日的補假事由。2027-12-31 的補假依原資料保留，雖對應跨年度連假，仍屬 2027 年的日期。
- 不把節日慶祝日等同放假日，不自行加入未列入原表的節慶；不推算 2028 年及之後的假日。資料為隨版本發布的靜態資料，不宣稱自動更新或涵蓋臨時停班停課。
- 來源授權：政府資料開放授權條款第 1 版（https://data.gov.tw/license）；鏡像依其 README 標示 CC BY 4.0。已保留原始出處及整理來源連結。

更新時請以最新政府公告核對，更新對應年度的靜態資料與測試，再重新部署。網站的「國定假日說明」提供原始資料及整理來源連結。
